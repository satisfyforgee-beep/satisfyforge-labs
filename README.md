# SatisfyForge Labs

Shared workspace for the SatisfyForge project.

## Layout

- `docs/` — notes, plans, and decisions
- `trading-lab/` — offline paper-execution/risk test harness (no live broker)
- `algo-trading/` — historical-bar strategy research and an isolated, opt-in Alpaca paper adapter
- `video-engine/` — owned FFmpeg video assembly and technical quality checks
- `src/` — source code
- `WORKSPACE.md` — how we collaborate in this repo

## Getting started

1. Clone the repo.
2. Read `WORKSPACE.md` for conventions.
3. Add notes to `docs/` and code to `src/`.
