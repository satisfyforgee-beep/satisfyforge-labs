# Rift Raiders v0.29 — Engine Physics, Interior Route and Multiplayer QA

**Private build:** `releases/rift-raiders/RiftRaiders-ChaosIslands-v0.29.rbxlx` (~48 MB), `feature/rift-raiders`. Date: October 18, 2026 EDT (Studio logs dated October 19 UTC). No public publish.

## Proven underlying defect

The first probe of the v0.28 build from a real Studio physics session showed the voxelized suburban Grass Terrain surface was **Y=2.515625**, despite the existing `Terrain:FillBlock(CFrame.new(0,-6,3600),Vector3.new(760,13,510), Grass)` being geometrically intended to top out at Y=.5. That buried roads with top Y=1.375 and covered the imported homes' actual interior floors at Y=1.8. The original character-volume overlap audit also mistakenly counted the *supporting floor* as a solid wall because its player capsule extended slightly below the walking surface.

## v0.29 final verified effects

- Local suburban terrain (and **only** that region's voxel fill) shifted from center Y=-6 to Y=-8 without altering dimensions/material; a Studio raycast sampling an unobstructed grassy location returned **Y=0.5** exactly.
- The existing asphalt road's upper surface is **Y=1.375** and real original house first-floor upper surfaces remain **Y=1.8**. The canonical Studio smoke now asserts grass below the road rather than relying on nominal FillBlock dimensions. Marker `SF_RIFT_CHECK terrain_voxel_clear_of_original_floor_and_roads PASS`.
- The prior v0.28 tests for genuine house-floor grounding and sloped paths also passed unchanged: `SF_RIFT_CHECK suburban_first_floor_ground_contact_and_sloped_walkways PASS`.

- **Actual Studio navigation/collision audit:** `V029_DEEP_INTERIOR_PASS`, process exit code 0. ## Known caveats / still blocked launch requirements

- A calculated Roblox navmesh path is substantial evidence the original door-to-first-floor approach is geometrically navigable. It is **not** a filmed human first-person traversal, animation/camera clipping audit, whole-house room-by-room test, or guarantee against every furniture obstruction. Original suburban upper-floor staircase navigation and every downtown tower remain unverified.
- Test-world doors are temporarily made noncolliding for pathfinding tests; the real multiplayer suite independently checks that actual player-triggered source doors move and become noncolliding. No unauthorized live-door shortcut was added to the game.
- Roblox Studio intermittent asset-compliance warnings from imported assets persist, including e.g. `rbxassetid://100804225678476` in a path test; no source/access permission audit is claimed complete. Also existing built-in RoundedCorner8 style warnings persist.
- Native iOS/Android graphics/controls/performance measurements, four-player private real experience, player DataStore leave/rejoin and concurrent-server acceptance, user playtests/retention, moderation/account content ratings and user permission for public release remain unmet.
- User-owned dirty historical `v0.21.rbxlx` working file and historical Studio `.lock` files were deliberately excluded from changes. No Robux, paid imports, in-game monetization, social publishing or real player save migration performed.
