## What is NOT established by these automated checks
- Collision clearance is measured at the entrance cross-sections, **not** exhaustive walk/navigation to every bedroom, shop aisle, upstairs landing, or garage furnishing. Real human keyboard/touch travel through each room remains a release gate.
- Testers were Studio-created clients, not a live four-player private Roblox experience with persistent DataStore leave/rejoin and concurrent server recovery.
- No Android/iOS low-end hardware FPS, thermal, memory, streaming, gamepad, or touch-control benchmarks exist. Roblox imported houses have thousands of parts; performance is an open risk.
- No official release/publishing/account asset permission QA. Studio intermittently logged an **asset noncompliance warning** for `rbxassetid://130957018166266`. The literal ID was not found in imported source and release XML by text search, but source is unknown; do not imply all imported assets render correctly on a published account.
- Minor Studio-owned `RoundedCorner8` StyleRule warning still appears.
- This is a private development build. No Robux charge, paid imports, live workflow activation, game publication, or change to the player's persisted save schema.
