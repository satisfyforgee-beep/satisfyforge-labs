# Rift Raiders v0.22 — QA evidence (2026-10-18)

## Reproducible result
- Rojo compiled `default.project.json` into `releases/rift-raiders/RiftRaiders-ChaosIslands-v0.22.rbxlx` (~47 MB).
- Roblox Studio 0.743.0.7431133, Mac arm64, executed `tests/roblox/rift_raiders_smoke.luau`: **SF_RIFT_SMOKE_PASS** after the final radius adjustment.
- The standalone two-client Roblox Studio test `tools/roblox-studio/run_rift_multiplayer.py` rebuilt the final source and returned **RIFT_MULTIPLAYER_PASS**, `SF_RIFT_MP_SERVER_PASS players=2`, and `SF_RIFT_MP_CHECK physical_retail_checkout_stock_pay_no_duplicates PASS`.
- The new retail regression covers wrong customer product, wrong shelf, remote interaction, attempted action at an adjacent station, unauthorized task shortcut, replayed scan/tip, and individual player HUD/wage state.
- Existing two-client checks for vehicles, weapons, world travel, activities, classic retail, cafe, garden, homes, suburban collectibles and mechanic services passed in that run.
- Final source check `git diff --check` produced no errors.

## Known limitations and warnings
- Roblox Studio printed built-in editor-style warnings for `RoundedCorner8` StyleRules; the smoke test did not report a critical game CreatorError.
- During a multiplayer session, Roblox's asset delivery logged `rbxassetid://84615966476385` as `Asset is not compliant` (403). The literal asset ID was **not found** in local Rift Raiders source or the prior release file. This could be an avatar/engine-supplied dependency, but its origin is unverified. Audit actual user-account asset permissions before public release.
- Automated tests are not a visual-quality or actual-device FPS guarantee. Physical Android/iOS frame time, memory, voice/UI accessibility, long-session leak tests, external asset permissions, and real private-place DataStore leave/rejoin tests remain release blockers.
- This prototype was not published publicly, did not enable Robux charging, and did not change the DataStore profile schema.
