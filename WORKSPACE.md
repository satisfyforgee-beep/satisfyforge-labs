# SatisfyForge Workspace

Initialized 2026-10-07.

## Conventions

- Work on short-lived branches and merge into `main`.
- Keep commits small, with clear messages.
- Record decisions in `docs/decisions.md`.
- Treat `docs/MASTER_COMMAND_CENTER.md` as the canonical non-sensitive index for work that used to be spread across chats and threads. Fold new recurring work into the existing master systems before creating duplicate loops, watchers, schedulers, repositories, sites, or dashboards.
- Operate cloud-first: use connected browser, GitHub, publishing, commerce, email, and outreach tools before depending on the owner's physical computer.
- Treat `docs/CLOUD_FIRST_OPERATIONS.md` as the operating guide for cloud-capable vs local-only work and blocker handling.
- Never incur a paid charge, start a paid trial, or store secrets in the repository without explicit owner approval.
