# SatisfyForge Brainrot Rush — Roblox Studio setup

This is an original, minimal playable prototype, not a published game.

1. Open Roblox Studio on Windows or macOS and create a Baseplate experience.
2. Open Explorer, then ServerScriptService.
3. Add a Script and paste the contents of `src/roblox/BrainrotRush.server.lua`.
4. Press Play to test. The script builds an arena and collectible orbs.
5. Touch an orb to increase the Brainrot leaderboard score.

Next steps: original character models, round timers, upgrades, persistence, mobile controls, anti-exploit validation, and playtesting.

No paid assets or external packages are required.
